Leonida Trophy Guide — an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: every official name, description and grade, a guide in our own words with its source for every trophy, a roadmap to the platinum, missable flags, and a checklist saved in your browser with export and import. No online trophies, no Rockstar artwork — just the guide.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
